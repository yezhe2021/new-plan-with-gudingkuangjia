# Fresh Static Memory trained on the frozen DST Stage2 base

Train a new input-independent M32 Static Memory plus four Rank16 construction adapters after Qwen blocks6/12/18/24 (409600 parameters). Fresh seed1234 initialization exactly matches the original Static experiment; do not continue the transferred old Static weights. The final DST Stage2 epoch4/step1536 checkpoint (`1d46e308fe1ddbf8297a67210b7f05df0f753842512c6779882477648b7d7cfc`), Llama and Qwen remain frozen and are checked after every update.

The static architecture is reused unchanged: only the fixed native public header and learned32 vectors enter canonical construction; no sample body or question enters the Memory construction path. Frozen Qwen remains differentiable to the prompt and adapters. The recipient length is used only for a deterministic K RoPE coordinate relocation; V and the entire DST body stay unchanged. Answering uses body+Memory in all36 layers and starts the suffix at L+32. Adapters act only during Memory construction. At fixed parameters, the canonical Memory content is identical for every input.

The DST engine preserves its existing complete RAW Full-Sync body interface. It computes the frozen body cache under no_grad, then allows gradients only through the separate Memory construction and Qwen readout. No Recolor/C translator weights are used to construct the training body. No new large cache or duplicated DST checkpoint is saved.

Data and budget exactly match the prior Static Memory training: ARC/HotpotQA/GSM8K1024 train and64 validation each,4epochs,1536 updates,batch8,AdamW1e-4,weight_decay1e-4,clip1. Full gold CE +0.5 full-vocabulary Native||Student KL. Gold CE covers complete targets; Native/Student rollouts cap64 and KL positions cap8. Prefix quotas are4/4/0,3/3/2,2/2/4,2/2/4 gold/native/student. The original semantic rows and schedules are unchanged; only DST-specific alignment indices are added. Native teacher prefixes are reusable read-only with pinned hashes because their Receiver/text interface is unchanged.

CPU checks use a real tiny36-layer Qwen to verify static input independence, causal all36 masks, cache invalidation after parameter updates and checkpoint-gradient equality. Endpoint parity reproduces frozen DST, Native and old Static transfer predictions on one question per task before baseline reuse. Disposable real GPU checks cover the longest example of each training task and four consecutive effective-batch8 updates, with finite connected gradients and unchanged DST/Sender/Receiver. Formal training starts from fresh initialization after these tests.

The fixed final epoch4 checkpoint is primary; per-epoch validation is diagnostic only. AMP rejects and retries the identical batch/RNG without skipping examples. Resume restores optimizer/scaler/RNG and archives step records beyond the last durable checkpoint. Checkpoints contain only the Memory/Adapter parameters and optimizer state, not the DST or LLMs.

After training, automatically evaluate the existing eight64-question cohorts, preserving prompts, scorers, labels, QA64/GSM512 generation limits and both GSM numeric metrics. Compare DST alone, DST+old Static (zero-shot), DST+new trained Static, Recolor+C+the same old Static and Native; save full predictions and paired question bootstrap summaries.

`python run_pipeline.py launch` runs a detached locked queue: prepare → scorer import checks → CPU checks → frozen endpoint parity → disposable GPU smoke → fresh full training → final evaluation. Pause requests are honored at batch/example boundaries. It can run after the laptop is shut down. No unrelated jobs or automatic uploads are started.

This experiment tests whether a shared calibration prefix needs adaptation to the new translator. It does not establish recovery of sample-specific information. All Memory arms have the same32-slot position shift; comparisons with DST alone still combine position and Memory effects. The cohorts were inspected previously and provide exploratory single-seed evidence. The known contradictory GSM952 benchmark label is retained.
