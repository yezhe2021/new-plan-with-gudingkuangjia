# A/C/D 分层原生KV替换与屏蔽：每个数据集64题

ARC、HellaSwag、HotpotQA各取原始固定顺序前64题，不依据答对/答错筛选。GSM8K不运行。冻结已有Recolor-KL A/C/D及Sender/Receiver，不重新训练。

对每种方法独立测试6组层：1–6、7–12、13–18、19–24、25–30、31–36。每组有原生K替换、原生V替换、原生KV替换、访问屏蔽四种干预，加上未干预基线共25种。每题另有一份共享Qwen原生基线；总计192题、14592个配置。

原生缓存来自同一Prompt的Qwen计算，仅作为离线Oracle使用。替换在最终缓存组装后完成，双方共享Qwen token网格、位置和post-k_norm/post-RoPE坐标；不重复归一化或旋转。替换和屏蔽范围一致，包含原传输Prompt中的问题、选项、证据；保留公开header，重新计算suffix/候选/答案，不重新计算原Prompt正文。不同组独立运行。

复用旧屏蔽实验中这192题已完成的4032个未干预/屏蔽结果，并记录来源路径及manifest。旧大规模任务已停止，已有结果保留。新实验单独目录，不混用旧128/512题总分。

启动检查覆盖原生缓存与原生直接prefill、全原生替换端点、全翻译历史基线、自身替换、所有组/组件的精确替换和公开header保护，及完整生成/候选评分。最长HotpotQA样本也参与检查。最终报告各配置绝对分、相对基线提升、替换相对同位置屏蔽提升、救回/损害题目、共同答对题保持数和Recovery Ratio。

本实验只定位局部原生信息的潜在价值；原生KV不构成可部署修复器。层组效应不保证可加，64题上的多重比较须留出集确认。
