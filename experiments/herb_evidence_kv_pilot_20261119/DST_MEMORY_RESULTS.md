# HERB DST + Rank64 + 门控动态 Memory 对照

新服务器 B 的 RTX 4090。复用同一批 8 道题、证据前缀、Qwen token 序列、贪心生成上限 192 和逐项判分标准。冻结原版 DST Stage 1、Rank64 残差及门控动态 Memory（M32+A4，固定第 1536 步）。用同一译后证据缓存比较读取 Memory 和关闭 Memory，回答位置保持一致。三份权重由已有评测加载器核验。原生输出 8/8 逐 token 复现，两个 DST 条件各 8/8 自然终止。
