# Full-Sync KV transfer experiments

This repository archives the fixed Full-Sync experiments after the ordered
copy/drop protocol was established. Each completed experiment has its own
directory under [`experiments/`](experiments/). Earlier code snapshots needed
by these scripts are kept as **code-only prerequisites** in sibling directories
so that their relative imports remain legible.

[`EXPERIMENT_RESULTS.md`](EXPERIMENT_RESULTS.md) and
[`MIGRATION_MANIFEST.json`](MIGRATION_MANIFEST.json) are generated by
[`tools/build_catalog.py`](tools/build_catalog.py) from the unmodified raw
artifacts. The manifest records the source path, source commit where available,
and SHA-256 of every copied file. Rebuild both files after adding a completed
experiment with `python tools/build_catalog.py`.

The first import was copied from `yezhe2021/weichaxun` branch
`codex/hidden-public-kv-mvp` at commit
`fb2719fe43fd8737e3e9019f5bf669ff7429badc`, except the completed
`fulltoken_sync_copydrop_v0_q4_to_g3_seed1234`, which was recovered from
`/home/yezhe/异构模型` on server A because it was absent from that GitHub commit.
Three GitHub snapshots with missing logs were supplemented with their
corresponding lightweight server logs; file-level provenance is recorded in
the manifest.
The still-incomplete Gemma→Qwen GSM8K run is intentionally not included.

No model weights, checkpoints, KV caches, or temporary tensors are included.
Some historical scripts contain absolute server paths and refer to checkpoints
that must be retrained before inference can be reproduced; archiving source and
results here does not imply the old checkpoints are downloadable.
